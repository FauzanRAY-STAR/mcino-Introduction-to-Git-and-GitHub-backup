# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based program that calculates the simple interest based on the principal amount, annual interest rate, and time period entered by the user.

This project demonstrates basic Bash scripting, user input handling, arithmetic operations, and displaying calculation results in the terminal.

## Formula

Simple interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate expressed as a percentage.
- **Time:** The investment or loan period in years.

The total amount is calculated as:

**Total Amount = Principal + Simple Interest**

## Features

- Accepts the principal amount from the user.
- Accepts the annual interest rate.
- Accepts the time period in years.
- Calculates simple interest using the standard formula.
- Displays the simple interest and total amount.

## Requirements

- A computer running Linux, macOS, or Windows with Git Bash or another Bash-compatible shell.
- Bash installed on the system.

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/FauzanRAY-STAR/mcino-Introduction-to-Git-and-GitHub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd mcino-Introduction-to-Git-and-GitHub
   ```

3. Run the script:

   ```bash
   bash simple-interest.sh
   ```

4. Enter the principal amount, annual interest rate, and time period when prompted.

## Example

Suppose the user enters:

- Principal: 1000
- Annual interest rate: 5%
- Time: 2 years

Calculation:

```text
Simple Interest = (1000 × 5 × 2) / 100
Simple Interest = 100
Total Amount = 1000 + 100
Total Amount = 1100
```
